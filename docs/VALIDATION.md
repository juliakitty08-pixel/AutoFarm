# 验证导航

本文件回答“证明什么、资格在哪、哪些没覆盖”。硬约束：本仓库的行为验证只能由人工完成。

## 1. 硬约束

- 所有测试必须由人工在 Windows + AutoHotkey v2 上执行。
- 不添加、不运行、不依赖自动化测试、测试脚手架或 agent 驱动的验证；覆盖范围为游戏宏、热键、时序循环与通知行为。
- `AutoHotkey64.exe /Validate <script>` 只做加载期语法检查，不执行脚本、不发送输入，不属于行为测试。
- 依据：[AGENTS.md](../AGENTS.md) 的测试约定与全局规则。

## 2. “已验证”的资格

一个改动只有在人工完成以下全部检查后才算已验证：

1. 启动受影响的脚本（`AutoHotkey64.exe source\AutoFarm_v5.ahk` 等），确认无启动报错。
2. 热键注册成功，开启/关闭都能触发；互斥循环按预期停止并弹出通知。
3. 开始/停止通知的文案、颜色、标签正确（`AutoFarmToggle` 等）。
4. 时序循环按 INI 设定运行：飒踏流星按住、千斤坠、神龙吐火、灵虚一指、闪避归位、采集间隔。
5. 修改 `source/autofarm.ini` 后，经热键重启任一循环即读到新值；非法热键会提示且本次不启动。
6. 无意外按键、无卡死、独山玉循环不会卡 5 分钟。

AutoSpace 的额外检查见第 4 节的 AutoSpace 行；它不适用独山玉、技能时序等 v5 专属项。

文档轮（只改 `.md`、链接或结构）不适用上述 1–6，但需完成静态检查：相对链接与文件存在、单一当前状态入口、未决项状态未被改写。

## 4. 手工检查清单（按改动类型）

| 改动类型 | 必查 |
|---|---|
| 热键/开关 | 注册、互斥停止、开始/停止通知、非法键回滚提示 |
| AutoSpace 热键/循环 | F9 注册与开始/停止通知；空格按 `KeyPressGap` 发送；`-`/`=` 只在运行中调整且通知显示新值；停止后 `-`/`=` 不再被占用 |
| AutoSpace 配置/写回 | 缺键回落；`KeyPressGap` <10 回落 200；`Adjustment` <1 回落 10；停止后 `autospace.ini` 的 `KeyPressGap` 为新值且中文注释保留；重新开启读取新值 |
| AutoSpace 冲突 | 与 AutoFarm 默认 `F9` 冲突；需要并用时改 `[Hotkeys] Toggle` 后人工确认 |
| 时序/循环 | 每段等待与按住时长、循环能否中途停止、独山玉不卡 5 分钟 |
| 配置加载 | 默认值、INI 覆盖、热键重启即时生效、缺键回落 |
| 通知/GUI | `Notifytest.ahk` 与 `Examples.ahk` 冒烟、同 tag 通知被替换 |
| 权限 | 非管理员启动会自提权；未新增提权路径 |
| 文档 | 链接、锚点、单一入口、未决项状态、容量 |

## 5. 覆盖边界

- 未覆盖：游戏客户端版本差异、实际网络延迟、多人世界刷新时机、不同分辨率/UI 缩放、系统权限策略、Release 资产上传、安装包完整性。
- 未覆盖：跨机器复现；本仓库不保存测试环境快照。
- 未执行：2026-11-09 文档轮未重跑 v5 行为验证；AutoSpace v1 仅做 `/Validate` 语法检查。任何脚本或 INI 默认值改动后必须补人工验证。
